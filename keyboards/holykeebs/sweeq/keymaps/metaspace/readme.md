# Building and flashing

```shell
qmk flash -j16 -kb holykeebs/sweeq --keymap metaspace -e USER_NAME=holykeebs -e POINTING_DEVICE=trackpoint_trackpoint -e SIDE=right
qmk flash -j16 -kb holykeebs/sweeq --keymap metaspace -e USER_NAME=holykeebs -e POINTING_DEVICE=trackpoint_trackpoint -e SIDE=left
```
